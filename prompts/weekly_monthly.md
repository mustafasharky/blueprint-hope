# Weekly review prompt

Read current machine data and tutor memory. Compare the latest seven-day window with
the preceding seven-day window by recomputing from dated attempt records. Summarize
sample sizes, unique-question counts, testing mode, timing caveats, recurring errors,
and performance on new versus repeated questions when the source supports it.
Select at most three priorities and explain what evidence would change each choice.
Adjust the next week's emphasis to the learner's stated availability. Preserve due
reviews and test one previously strong area. Save the planning decision, not invented
practice completion, to tutor memory.

# Monthly review prompt

Read the same sources. Compare the latest 30 days with the preceding 30 days only
where adequate comparable evidence exists. Review full-length/section score history
separately from Qbank results. Identify persistent bottlenecks, under-sampled skills,
retention failures, and interventions that helped or failed. Revisit learner-reported
constraints and ask whether stale constraints still apply. Update the compact memory
summary with dated evidence links. Do not claim that a changed score was caused by
the tutoring intervention without an adequate basis.
